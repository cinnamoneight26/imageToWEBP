# 📍 imageToWEBP 🌟

## 📜 Project Description
imageToWEBP is a delightful web application that allows users to easily upload images and convert them to the `.webp` format! Built with React, this project aims to provide a user-friendly experience for processing images. 🖼️✨

## 🌟 Features
- **📤 Image Upload**: Users can select and upload images from their device.
- **🔄 WEBP Conversion**: Automatically converts uploaded images to `.webp` format.
- **🖼️ Multiple Image Selection**: Select multiple images at once for batch conversion.
- **⚙️ Resize Options**: Customize width and height before converting.
- **📥 ZIP Download**: Download all converted images as a ZIP file.
- **📛 Input Validation**: Prevents conversion when required dimensions are missing, and shows helpful toast messages.
- **📱 Responsive UI**: Optimized for both desktop and mobile devices.

## 🆕 What's New
- You can now **add custom size options** (width/height) for each image.
- Resize options are **validated** before conversion — missing values trigger toast notifications.
- Converted images can be **downloaded individually or as a ZIP**.
- **Progress indicators** and improved error handling have been added.
- UX enhancements including **focus on invalid fields** and **responsive layout improvements**.

## 🛠️ Tech Stack
- **React**: For building the user interface
- **HTML5**: For markup structure
- **CSS**: For styling
- **JavaScript**: For dynamic functionality
- **JSZip**: For creating downloadable ZIP archives
- **React-Bootstrap + Toastify**: For UI and notifications
